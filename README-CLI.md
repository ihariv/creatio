
Скрипт `creatio.cli.ps1` — это единая точка входа для управления локальными Docker-окружениями Creatio (такими как `dev1`, `dev2`). Он позволяет деплоить инстансы, управлять портами, сбрасывать пароли, настраивать режимы разработки (FSD) и устанавливать приложения из архивов.

## Требования
- PowerShell (Core или Windows)
- Docker Desktop / Docker Engine
- Установленная глобально утилита [clio](https://github.com/Advance-Technologies-Foundation/clio) (`dotnet tool install clio -g`)

---

## 🛠 Доступные команды

### 1. `status` (по умолчанию)
Отображает список всех запущенных и остановленных окружений, а также их порты (HTTP, Database, Redis).

**Пример использования:**
```powershell
.\creatio.cli.ps1 status
# Или просто:
.\creatio.cli.ps1
```

### 2. `reset-all` (Сброс к заводским настройкам)
Полностью удаляет данные и пересоздает **все** окружения (по умолчанию `dev1` и `dev2`) "с нуля". **Внимание: все несохраненные данные в БД и папке `runtime` будут уничтожены**. Базы данных будут восстановлены из исходного бэкапа `.backup`.

**Пример использования:**
```powershell
.\creatio.cli.ps1 reset-all
```

### 3. `deploy <имя_окружения>` (Развертывание без потери данных)
Разворачивает новое окружение (если его не было) или обновляет конфигурацию существующего, **сохраняя данные в базе и на файловой системе**. Подбирает свободные порты, генерирует `Terrasoft.WebHost.dll.config` и `ConnectionStrings.config` из шаблонов.

**Пример использования:**
```powershell
.\creatio.cli.ps1 deploy dev1
```

### 4. `rebuild-image <имя_окружения>` (Пересборка Docker-образа)
Выполняет пересборку Docker-образа `creatio` для указанного окружения без использования кэша. Делает `docker compose down`, пересобирает образ (`--no-cache --pull`) и принудительно пересоздает контейнер (`--force-recreate`). **Данные в БД и выгруженные пакеты сохраняются.** Полезно при изменении `Dockerfile` или обновлении базового образа.

**Пример использования:**
```powershell
.\creatio.cli.ps1 rebuild-image dev2
```

### 5. `restart <имя_окружения>`
Выполняет мягкую перезагрузку контейнера Creatio (аналог `docker compose restart`). Быстрый способ применить изменения конфигурационных файлов (IIS/Kestrel).

**Пример использования:**
```powershell
.\creatio.cli.ps1 restart dev1
```

### 6. `clean`
Останавливает и удаляет все контейнеры, удаляет Docker volumes и **полностью удаляет** папку `runtime` со всеми логами и исходниками на диске.

**Пример использования:**
```powershell
.\creatio.cli.ps1 clean
```

### 7. `reset-password <имя_окружения>`
Принудительно сбрасывает пароль пользователя `Supervisor` в базе данных указанного окружения на значение `Supervisor` (напрямую через SQL-запрос). Полезно, если вы забыли пароль после манипуляций с БД.

**Пример использования:**
```powershell
.\creatio.cli.ps1 reset-password dev1
```

### 8. `enable-fsd <имя_окружения>`
Включает **File System Development Mode** (режим разработки в файловой системе) для указанного окружения. Скрипт модифицирует файл `Terrasoft.WebHost.dll.config` и перезапускает контейнер Creatio.
*Примечание: после выполнения команды зайдите в Creatio -> Configuration -> Actions -> Download packages to file system.*

**Пример использования:**
```powershell
.\creatio.cli.ps1 enable-fsd dev1
```

### 9. `install-pkg <имя_окружения> <путь_к_zip>`
Устанавливает **Пакет** (Package) из `.zip` или `.gz` архива (экспортированного из раздела Конфигурация) в указанное окружение с помощью команды `clio push-pkg`.

**Пример использования:**
```powershell
.\creatio.cli.ps1 install-pkg dev2 "..\application\MyCustomPackage.zip"
```

### 10. `install-app <имя_окружения> <путь_к_zip>`
Устанавливает полноценное **Приложение** (Application) из `.zip` архива (экспортированного из Application Hub) в указанное окружение с помощью команды `clio push-app`.

**Пример использования:**
```powershell
.\creatio.cli.ps1 install-app dev2 "..\application\UsrYachts_2026-02-18_19.09.22.zip"
```

### 10. `sync-clio`
Сканирует запущенные окружения, собирает их порты и автоматически генерирует (синхронизирует) файл `clio-envs.json` в корне проекта. Это позволяет утилите `clio` знать о ваших локальных окружениях.

**Пример использования:**
```powershell
.\creatio.cli.ps1 sync-clio
```

### 11. `install-gate <имя_окружения|all>`
Устанавливает "шлюз" ClioGate в указанное окружение (или во все запущенные). ClioGate необходим для расширенных операций `clio` с инстансом.

**Пример использования:**
```powershell
# Установить только на dev1
.\creatio.cli.ps1 install-gate dev1

# Установить на все запущенные окружения
.\creatio.cli.ps1 install-gate all
```

## 🔄 Типовые сценарии (Workflows)

### Сценарий 1: Разработка с использованием внешней IDE (Rider/Visual Studio)
1. Разверните окружение: `.\creatio.cli.ps1 deploy dev1`
2. Включите режим FSD: `.\creatio.cli.ps1 enable-fsd dev1`
3. В браузере (Configuration) выгрузите пакеты на диск.
4. Пишите код в IDE в папке `runtime/dev1/Terrasoft.Configuration/Pkg/...`.
5. Компилируйте изменения через интерфейс Creatio.

### Сценарий 2: Перенос приложения из dev1 в dev2
1. Убедитесь, что оба окружения развернуты (`deploy`).
2. Сделайте экспорт вашего приложения (например, `UsrYachts`) из `dev1` через Application Hub в виде `.zip` файла.
3. Установите **приложение** в `dev2`:
   ```powershell
   .\creatio.cli.ps1 install-app dev2 "..\путь\к\UsrYachts.zip"
   ```
   *(Если вы экспортировали отдельный пакет из конфигурации, используйте `install-pkg`).*

### Сценарий 3: Добавление нового окружения (например, dev3) к уже имеющимся
Если у вас уже работают `dev1` и `dev2`, и вам срочно потребовалось еще одно изолированное окружение:
1. Вызовите команду развертывания с новым именем:
   ```powershell
   .\creatio.cli.ps1 deploy dev3
   ```
2. Скрипт автоматически найдет свободные порты, создаст для него папку в `runtime/dev3`, развернет БД из бэкапа и запустит контейнеры.
3. Посмотрите выделенные порты командой `.\creatio.cli.ps1 status`.

### Сценарий 4: Применение ручных изменений конфигурации
Если вы вручную отредактировали `Terrasoft.WebHost.dll.config` или `ConnectionStrings.config` в папке `runtime/dev1/`, выполните мягкую перезагрузку:
```powershell
.\creatio.cli.ps1 restart dev1
```

### Сценарий 5: Пересборка Docker-образа при проблемах с кэшем
Если вы изменили `creatio/Dockerfile` (например, добавили установку новых системных пакетов в Linux) или нужно гарантированно скачать свежие зависимости, выполните:
```powershell
.\creatio.cli.ps1 rebuild-image dev1
```
При этом ваша база данных и ваши файлы с кодом останутся нетронутыми.

### Сценарий 6: Сброс окружений
Если вы безнадежно сломали схему базы данных или пакеты, и хотите начать с чистого листа:
```powershell
.\creatio.cli.ps1 reset-all
```
Это удалит всё и восстановит "чистую" БД из `BPMonline833StudioNet8.backup`.
